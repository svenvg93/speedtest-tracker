*[CLI]: Command-line interface
*[cron]: A time-based schedule format, e.g. 0 * * * * runs every hour
*[DNS]: Domain Name System, translates hostnames into IP addresses
*[FQDN]: Fully qualified domain name, e.g. db.example.com
*[ICMP]: Internet Control Message Protocol, used by ping
*[ISP]: Internet service provider
*[PGID]: The group ID the container runs as, find it with id $user
*[PUID]: The user ID the container runs as, find it with id $user
*[SMTP]: Simple Mail Transfer Protocol, used to send email
*[UTC]: Coordinated Universal Time
*[WAN]: Wide area network, your public internet connection
