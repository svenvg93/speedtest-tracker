# Charts

You can find these settings under **Settings → General → Charts**.

| Setting | Default | Description |
| --- | --- | --- |
| Default chart range (days) | `7` | The number of days shown by default when a chart first loads. Must be at least `1`. |

The default is set on the first start from the [`DEFAULT_CHART_RANGE_DAYS`](../../installation/environment-variables.md#display) environment variable. After that, changing the variable has no effect, so change it here instead.
